NEW!!! A step-by-step guide to setting up your local development environment, saving your progress, and hosting your site online.

1. Setting Up Your Local Environment: VS Code

Visual Studio Code (VS Code) is your IDE (Integrated Development Environment). It is where you will write your code, manage your project files, and preview your website.

Step-by-Step Setup:

  1. Download & Install: Grab it from code.visualstudio.com.
  2. Open a Folder: Create a new folder on your computer called lilydipper-website (or whatever) and drag it into the VS Code window. This is your project workspace.
  3. Install Live Server: Click the Extensions icon on the far left (it looks like four squares). Search for Live Server (by Ritwick Dey) and click Install.

2. Saving Your State: GitHub Desktop

If you've ever had files named Final_Mix_v2_ActuallyFinal.wav, you know file management can get messy. GitHub Desktop tracks every single change you make and backs it up to the cloud.

Step-by-Step Setup:

  1. Create an Account: Go to GitHub.com and make a free account. Make sure you pick a username you like!
  2. Get the App: Download and install GitHub Desktop. Sign in.
  3. Create a Repository: In GitHub Desktop, go to File > New Repository. CRUCIAL STEP: You must name the repository exactly yourusername.github.io (replace "yourusername" with your actual GitHub username). Set the local path to your project folder, and click Create.
  4. Publish: Click the blue Publish repository button. Important: Uncheck "Keep this code private" (it needs to be public for free hosting).

3. Going Live: GitHub Pages

The best part about GitHub is that they will host your static files (HTML/CSS) for free using a feature called GitHub Pages.

  1. Go to GitHub.com and navigate to your new repository.
  2. Click the Settings tab (the gear icon near the top right).
  3. On the left sidebar, click on Pages.
  4. Under "Build and deployment", look for Source. Make sure "Deploy from a branch" is selected.
  5. Under the Branch dropdown, select main (or master) and leave the folder as / (root). Click Save.

That is it! GitHub will provide you with a live URL, which will be exactly what you named your repository: https://yourusername.github.io. Every time you "Push" changes from GitHub Desktop, your live website will automatically update.

4. Your First Track: Starter HTML

Create a file named index.html in your VS Code folder. Click the button below to copy the code, paste it into that file, and save it. Then, right-click and hit Open with Live Server to see your band site in action.

5. Prompting the AI

Now that your environment is fully operational, it is time to let the computers do the heavy lifting. Open up your favorite AI and ask it to write the code for you.

How to talk to the machine:

  • Be Specific About Style: Tell it exactly what you want it to look like (e.g., "Make it look like a 90s hacker movie" or "Make it clean and modern like Apple").
  • Be Specific About Function: What does the site actually need to do? ("I need a music player," "I need a contact form for booking.")
  • THE GOLDEN RULE: Tell it to go STEP BY STEP. If you do not explicitly ask this, the AI will spit out 500 lines of code at once and your brain will melt.
